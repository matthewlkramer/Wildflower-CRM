Use the uploaded Wildflower Montessori Style Guide PDF in `attached_assets/` as
the visual authority for Wildflower CRM design work. Its core identity uses
dark teal `#137070` for text, bright teal `#00a69c`, the six-color primary
palette, watercolor artwork, Mrs Eaves-style serif headings, and Mr
Eaves/Avenir-style sans-serif text.

**Why:** An earlier refresh inferred a forest-and-cream identity from the small
existing app logo. The supplied guide shows a brighter, multicolor watercolor
identity and explicitly defines the approved palette and typography.

**How to apply:** Check the guide before changing shared UI styling or creating
new branded assets. Use Garamond and Avenir/Helvetica-compatible substitutions
when the licensed Mrs Eaves and Mr Eaves font files are unavailable.
